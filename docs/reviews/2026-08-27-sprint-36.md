# Sprint 36 — Sprocket s6 asserted something no child had done

**Date:** 2026-08-27
**Scope:** one P1 content/data-integrity finding, in one scene of one mission.

## The finding

`Sprocket Wants to Know`, scene `s6`, opened with:

> Sprocket already knows your first name. Which of these would you not add to it?

It does not. The scene then awarded `privacy.identity` **demonstrated** for
choosing the school, on feedback that reasoned from that premise — so the
evidence rested on a fact the child's own authored path contradicted. For this
age group the product reports that choice to a teacher as skill evidence rather
than as story completion, which is what makes it a data-integrity defect and not
only a continuity slip.

## The trace, path by path

Every route into `s6` was walked by hand. `s2` is the only scene where the name
is at stake, and it has three choices:

| `s2` choice | Retry? | Name given? | Route to `s6` |
|---|---|---|---|
| `c1` "Type your first and last name" | **yes** — loops to `s2` | no, the child is sent back | never exits here |
| `c2` "Leave it blank and tap Start" | no | **no** | `s3 → s4 → s5 → s6` |
| `c3` "Lean over and ask Theo what he typed" | no | **no** — the child asks a peer and types nothing | `s3 → s4 → s5 → s6` |

`s3`, `s4` and `s5` are then common to both routes: `s3` is a story scene, and
`s4` and `s5` have no exit that supplies a name — `s4` is about school and
street, `s5` about birthday and a caregiver email. `s4/c2` gives up the school
on one path, but no path anywhere gives up a name.

So the premise was false on **both** non-retry routes, not only the full-credit
one. The single path on which a name is typed is `s2/c1`, which is a retry: it
loops back to `s2` and cannot reach `s6` without the child then choosing `c2` or
`c3`. There was no route through this mission on which the scene's opening
sentence was true.

Theo types his full name in `s3`, and that is almost certainly where the line
came from. It is his name, not the player's, and the scene said "your".

## What changed

**The premise is now an explicit hypothetical.** Ms. Okafor says "Let's
pretend", and the prompt repeats it so a class that skims the narration still
gets it:

> Imagine an app already knows a kid's first name. Which of these would you not
> add to it?

Framed as "a kid" rather than "you", for two reasons: it is true regardless of
which route the child took, and it does not quietly rewrite the safe choice at
`s2` into having shared something. The choice labels moved to match ("Which
school **they** go to").

**The school and street explanations now teach stacking rather than
identification.** The old copy claimed too much:

- School: "somebody knows where one particular child is, five mornings a week"
- Street: "A name and a street is nearly a doorstep"

A first name plus a school does not pick out one child — Room 12 alone has
twenty-three, and a school has hundreds. The rule that is both durable and
true is that each detail narrows the field:

- School → "Plenty of kids share a first name. Add a school and now it is only
  the kids at that one school, on a weekday morning. The group got a lot
  smaller."
- Street → "Where somebody lives is one of the strongest details there is.
  Stack it on a first name and the list of kids it could be gets very short.
  That is why it stays private."

Neither claims certainty has been reached, and both survive a child who
objects "but lots of kids are called Sam" — which the old copy did not.

**Dinosaurs stay the genuine public contrast**, and are now contrasted on the
same axis rather than a different one: "Lots of kids like dinosaurs. Adding
that does not make the group any smaller, and it does not say where anybody is.
Look for one that adds a place. There is more than one."

**Sprint 17's safeguard is intact.** Two non-retry exits, both
`privacy.identity` demonstrated, one retry that loops. Finishing the scene is
still not the same as mastering it, and the final sentence still tells the child
that both school and street are correct, so neither exit is a trick.

**Evidence alignment is unchanged and unchanged by design.** Content declares
`demonstrated`; the coached-retry downgrade is applied by `recordDecision` and
is exercised against this exact scene in `tests/evidence-integrity.test.ts`.
Verified live below.

## Tests

The assertion that pinned the false history is gone. Two tests replace it, and
both were confirmed to **fail against the old content and pass against the
new** by stashing the content file and re-running.

1. *"states its premise as a hypothetical, because no path establishes it"* —
   the prompt itself contains `imagine`, the scene opening contains
   `pretend|imagine`, and it never says `already knows your` or `you
   gave/typed/told`.
2. *"teaches that details stack, without claiming one child has been
   identified"* — exactly two non-retry exits; the copy contains
   `smaller|narrows|short`; it does not contain `one particular child`,
   `knows where/who ...`, `nearly a doorstep` or `exactly where`; and the
   dinosaur option is still a retry, still carries no evidence, and still
   points at `place`.

463 tests, up from 461.

## Verified in the product

**Projector (Classroom Mode).** Stepped to Decision 4 of 4 and revealed all
three branches. Both school and street render as **SAFE CHOICE**, dinosaurs as
**LOOPS BACK**; narration and prompt fit the board without truncation.

**Tablet (768×1024), played as a child.** Joined Room 12, played the route the
false premise contradicted — `s2/c2` "leave it blank" — through `s4/c1` and
`s5/c1` to `s6`. The scene reads as a hypothetical, three options are legible
without scrolling past the art, the feedback renders, and the mission completes
with the Name Keeper badge. The stored attempt afterwards:

```
path      s2:c2 -> s4:c1 -> s5:c1 -> s6:c1
evidence  {"privacy.identity":"demonstrated","privacy.escalate":"demonstrated"}
```

A clean first-go path records demonstrated, as it should.

## Deliberately not changed

- **No open chat, no free text, no student fields, no unrelated sweep.** One
  scene of one mission.
- **`s2`'s safe choice is untouched.** The finding was explicit that the fix
  must not rewrite it into sharing data, and it does not.
- **`s3`'s "Theo typed his whole name"** stays. It is true, it is his, and it is
  the contrast the mission is built on.
- **`s4/c2` still concedes the school on one path.** The `s6` hypothetical is
  independent of it, so no conflict arises.

## The lesson

**A shared scene inherits every path into it, and the copy has to be true on
all of them.** This scene reads perfectly if you arrive imagining the child
typed a name at `s2` — which is exactly the branch the mission is designed to
talk them out of. The rule is not "check the scene", it is "check the scene
against each predecessor", and the reason it matters more here than in a story
scene is that this one converts a click into a competency claim about a child.

Twenty-six of the twenty-seven missions still have untraced shared scenes.
This is the first one traced.
